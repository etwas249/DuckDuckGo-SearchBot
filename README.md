# DuckDuckGo-SearchBot
Бот-поисковик DuckDuckGo в Telegram, использующий технологию inline-запросов (подобно @pic и @vid).

Для начала взаимодействия с программой, вставьте токен вашего бота в значение "token" файла appsetting.json, предварительно настроив бота на inline режим и установив Inline Feedback на 100%.

## Требуемые Nuget-пакеты
* Telegram.Bot (22.10.3.1)
* Newtonsoft.Json (13.0.4)
* HtmlAgilityPack (1.13.1)
* Esprima (3.0.6)
